# بوت كنيسة الكتاب المقدس المعمدانية – القدس

واجهة محادثة مستقلة على نفس تطبيق Flask الموجود. صفحة الكنيسة تبقى للمتابعة اليدوية؛ لا يتطلب الويب توكن Meta أو موافقة مسنجر.

## ما تعمل عليه هذه النسخة

- `/`: المحادثة، عربية وإنجليزية، مع معلومات الكنيسة وأزرار المواعيد والعنوان والعائلة.
- `/api/chat`: استقبال سؤال الويب فقط. لا يُرسَل إلى صندوق رسائل الصفحة.
- `/status`: حالة الخدمة التي كانت سابقًا على `/`.
- `/health`: فحص التشغيل.
- `/chat-privacy`: خصوصية المحادثة المستقلة.
- `/privacy` و`/data-deletion`: صفحات تكامل Meta القديم محفوظة دون تغيير.
- `/static/share-card.png`: بطاقة معاينة رابط المنشور. مؤقتة، وليست صورة الكنيسة الأصلية.

## حدود الأجوبة ومصادرها

الأجوبة الروحية في النسخة الحالية هي مكتبة المشروع الموجودة (15 موضوعًا). حُفظت النصوص العربية، وأُضيفت تفسيرات إنجليزية موجزة لنفس المواضيع. Groq، عند وجود مفتاحه، يصنّف السؤال إلى موضوع معرّف مسبقًا فقط؛ لا يُعرض نص مولَّد منه للزائر. لا يكتب النموذج الآيات أو المراجع.

كل نص آية في محادثة الويب يُجلَب من eBible: `arb-vd` للعربية و`eng-kjv` للإنجليزية. لا تُستخدم نصوص الآيات المحلية القديمة كبديل في محادثة الويب. إذا فشل الجلب أو لم يوجد الشاهد، يُعرض تعذّر التحقق. تُحفظ الإصحاحات مؤقتًا بحد أقصى 128 إصحاحًا في ذاكرة العملية. طلب الإصحاح أو النطاق الطويل يعرض حتى خمس آيات، مع رابط النص الكامل.

الموقعان baptistarabic.org وar.thegospelcoalition.org **روابط قراءة إضافية فقط في هذه النسخة**. لم تُضف ميزة البحث في مقالاتهما أو استخراج أجوبة جديدة منها. توسيع المكتبة بمحتواهما، ومراجعة المواد بحسب الفكر المعمداني المستقل، عمل منفصل لم يُنفَّذ هنا. لا تفترض أن كل محتوى الموقعين معتمد تلقائيًا للكنيسة.

الأسئلة غير المدعومة لا تحصل على تفسير مرتجل، ولا يُقال إنها وصلت للكنيسة. رابط التواصل يفتح مسنجر بإرادة الزائر، ليجيب فريق الكنيسة يدويًا.

## تشغيل محلي

```bash
python3 -m pip install -r requirements.txt
python3 app.py --port 5000
```

اختبارات بدون اتصال بفيسبوك أو Groq:

```bash
python3 -m unittest discover -s tests -v
```

## رفع النسخة إلى GitHub ثم Render

1. ارفع الملفات الجديدة والمعدّلة كلها إلى المستودع، مع إبقاء `templates/` و`static/` و`tests/` كمجلدات. لا ترفع `.env` أو ملفات الأسرار.
2. في خدمة Render الحالية افتح **Environment** واضبط:

| المتغير | القيمة |
| --- | --- |
| `FACEBOOK_ENABLED` | `0` |
| `COMMENTS_ENABLED` | `0` |
| `WEB_AI_ENABLED` | `1` (اختيار موضوع بواسطة Groq فقط) |
| `ALLOW_GROQ` | `0` (الإجابات الحرة القديمة تبقى معطّلة) |
| `PUBLIC_URL` | `https://bible-baptist-bot.onrender.com` |

احتفظ بمفتاح `GROQ_KEY` أو `GROQ_API_KEY` الموجود. لا حاجة لتغيير توكن Meta، ولا لتفعيل `/setup`. تبقى معلومات الاجتماعات والعنوان الافتراضية كما هي؛ ومتغيرات `CHURCH_SERVICE_TIME` و`CHURCH_ADDRESS` و`CHURCH_MAPS_URL` الحالية تتقدّم على الافتراضيات كما في المشروع الأصلي.

`TRUST_RENDER_PROXY=1` اختياري فقط خلف وكيل Render الموثوق لتحسين تمييز زوار حدود الطلبات. الوضع الافتراضي لا يثق بهيدر يرسله الزائر، وقد يشترك الزوار بحد واحد حسب إعداد الوكيل. حدود هذه النسخة مؤقتة في عملية واحدة؛ للتوسع استخدم مخزن حدود مشتركًا ولا ترفع عدد العمال دون تعديل ذلك.

3. **Settings → Build & Deploy**: أمر البناء `pip install -r requirements.txt`، وأمر التشغيل:

```text
gunicorn --workers 1 --threads 4 --timeout 90 app:app
```

ملف `gunicorn.conf.py` يضبط نفس القيم تلقائيًا حتى لو بقي أمر التشغيل القديم `gunicorn app:app`؛ الخيارات الصريحة في أمر التشغيل تتقدّم على الملف.

4. اختر **Manual Deploy → Deploy latest commit** إذا لم يبدأ النشر التلقائي.
5. بعد نجاح النشر، افتح `/status`: يجب أن يعرض `facebook_enabled:false` و`comments_enabled:false`. قيمة `groq_enabled:false` تخص مسار فيسبوك القديم وليست مؤشرًا على فهم سؤال الويب.
6. افتح الرابط الرئيسي. جرّب المواعيد والعنوان، ثم «مين هو يسوع؟»، و«يوحنا 3:16»، و`John 3:16`. يجب أن تكون الآية الإنجليزية KJV. جرّب «متى يرجع المسيح؟»: يجب ألا يعرض مواعيد الاجتماعات.
7. اختبر من الهاتف قبل الإعلان. الاستضافة المجانية قد تحتاج وقتًا للاستيقاظ بعد الخمول؛ الواجهة تعرض رسالة انتظار ومحاولة إعادة عند تعذّر الاتصال. لا يوجد ضمان سرعة ثابتة على الخطة المجانية.

**تعديل `render.yaml` لا يضمن تغيير متغيرات خدمة موجودة أُنشئت يدويًا**؛ افحص Environment وStart Command فعليًا. تجنّب إنشاء خدمة جديدة مدفوعة. الملف يحدد `plan: free` للإنشاء عبر Blueprint.

## ربط صورة المنشور بالمحادثة

انشر **رابط المحادثة** وانتظر ظهور بطاقة المعاينة، بدل رفع صورة عادية والافتراض أنها تفتح الموقع. الصفحة تحتوي وسوم Open Graph بعنوان وصورة 1200×630. يمكن استبدال `static/share-card.png` بالصورة الأصلية المطلوبة بعد تجهيزها بنفس القياس. إذا غُيّرت الصورة، استخدم اسم ملف جديد وحدّث `og:image` لتجنب الصورة القديمة المخزنة مؤقتًا عند فيسبوك.

لا تنشر الإعلان قبل التأكد أن الرابط العام يعرض المحادثة الجديدة فعليًا. النشر على GitHub أو نجاح الاختبارات محليًا لا يعني أن Render نُشر تلقائيًا.

## إعادة ربط Meta لاحقًا

الكود القديم محفوظ، لكنه لا يعالج أحداث POST ولا ينفذ `/setup` ما دام `FACEBOOK_ENABLED=0`. بعد الموافقات وفحص منع تكرار التعليقات، يمكن إعادة تفعيل القنوات المطلوبة بشكل مستقل. لا تفعّلها لمجرد انتهاء Business Verification؛ صلاحيات التطبيق والنشر تحتاج فحصًا منفصلًا.

## ما تم التحقق منه

- اختبارات محلية للمراجع، فصل القنوات، إدخال المستخدم، حدود الطلبات، رفض مصدر خارجي، ومنع تسرب نص النموذج إلى الرد.
- فحص مباشر لنص يوحنا 3:16 من eBible بالعربية وبـKJV.
- فحص بصري لنسخة الواجهة على سطح المكتب وبعرض هاتف 390 بكسل بالعربية والإنجليزية.
- المعاينة البصرية لقطة واجهة ساكنة؛ API اختُبر عبر عميل Flask، وليس عبر خدمة Render المنشورة.
- لم تُختبر استجابة Groq الحية لعدم توفر مفتاح في بيئة التطوير؛ اختُبر مساره باستجابات محاكاة. لم تُرسل رسائل أو تعليقات إلى فيسبوك.
